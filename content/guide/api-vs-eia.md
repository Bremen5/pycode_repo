米国の週間の石油在庫については、毎週2つの統計が伝えられます。ひとつは業界団体である **米国石油協会（American Petroleum Institute、API）** の統計、もうひとつは政府機関である **米エネルギー情報局（EIA）** の統計です。どちらも「原油在庫が〇〇万バレル減少」といった形で報道されるため混同されやすいのですが、発表元も調査の方法も異なります。このページでは、2つの統計の違いを整理します。

## 一覧で比べる

| 項目 | API統計 | EIA統計 |
|---|---|---|
| 発表元 | 米国石油協会（業界団体） | 米エネルギー情報局（米国エネルギー省の統計機関） |
| 正式な名称 | Weekly Statistical Bulletin | Weekly Petroleum Status Report |
| 発表時刻（米東部時間） | 通常 火曜 16:30 | 通常 水曜 10:30 |
| 発表時刻（日本時間） | 通常 水曜 5:30（夏時間）／6:30（冬時間） | 通常 水曜 23:30（夏時間）／木曜 0:30（冬時間） |
| 報告のしかた | 会員企業などからの任意の報告 | 対象企業に報告義務がある調査 |
| 入手のしかた | 詳細は有料の購読者向け | 誰でも無料で閲覧・取得できる |

※祝日がある週は、どちらも発表が遅れることがあります。

## 発表元と性格の違い

APIは、米国の石油・天然ガス産業の企業が加盟する業界団体です。週間統計は、会員企業などから寄せられた報告をもとに集計され、主に購読者向けに提供されています。報道機関がその概要を伝えるため、一般には「API統計によると」という形で目にすることが多くなります。

一方、EIAは米国エネルギー省の中の統計・分析機関で、法律にもとづいて企業にデータの報告を求める権限があります。製油所、ターミナル、パイプライン会社、輸入業者などが調査の対象で、集計結果はEIAのウェブサイトやAPIで誰でも無料で利用できます。本サイトが扱っているのはこのEIA統計です。

## 調査方法の違い

最も大きな違いは、報告が任意か義務かという点です。

APIの統計は任意の報告にもとづくため、報告する企業の範囲がEIAより限られる場合があり、報告されなかった部分を推計で補っています。EIAの統計は報告義務のある調査にもとづいており、対象範囲が広いことから、一般に網羅性が高いとされています。

このため、市場関係者の間では、APIの統計を「EIA統計の前日に出る先行的な目安」として扱い、EIAの統計を週間の公式な数字として扱うのが一般的です。

## 数字がずれる理由

APIとEIAの数字は、同じ週についても一致しないことがよくあります。場合によっては、増減の方向が逆になることもあります。主な理由は次のとおりです。

- **対象範囲の違い**：報告している企業や施設の範囲が異なります。
- **推計方法の違い**：報告が足りない部分の補い方が異なります。
- **集計のタイミング**：報告の締め切りや修正の扱いが異なることがあります。
- **輸入量の振れ**：タンカーの到着など、週ごとに大きく変わる項目は、わずかな集計の違いでも結果に差が出やすくなります。

どちらかの数字が「正しく」、もう一方が「誤り」というわけではありません。調査の設計が違う別々の統計として理解するのが適切です。

## 報道を読むときのポイント

ニュースでは「API統計では原油在庫が減少、EIA統計では増加」のように、2つの統計の違いが話題になることがあります。報道を読むときは、次の点を意識すると混乱しにくくなります。

1. **どちらの統計の数字か** を確認する。見出しに「API」と「EIA」のどちらが書かれているかを見ます。
2. **何の在庫か** を確認する。原油在庫なのか、ガソリン在庫なのか、クッシングの在庫なのかで意味が変わります。
3. **SPR（戦略石油備蓄）を含むかどうか** を確認する。「原油在庫」は通常、SPRを除いた民間の在庫です。
4. **市場予想との比較** として報じられている場合、その予想は報道機関などが独自に集計したもので、統計そのものではありません。

## EIA統計を確認する方法

EIA統計は、発表時刻になるとEIAのウェブサイトの [Weekly Petroleum Status Report のページ](https://www.eia.gov/petroleum/supply/weekly/) で公開されます。要約（Highlights）のほか、項目ごとの詳しい表や、過去にさかのぼった時系列データも無料で確認できます。

本サイトでは、そのEIA統計をもとに、前週比・前年同週比・過去5年の同じ週との比較を計算し、日本語の解説とグラフにまとめています。APIの統計は購読者向けのデータであるため、本サイトでは扱っていません。

## まとめ

- APIは業界団体、EIAは政府の統計機関です。
- APIは任意の報告、EIAは報告義務のある調査にもとづきます。
- APIは通常火曜日の夕方（米東部時間）、EIAは通常水曜日の午前（同）に発表されます。
- 2つの数字は一致しないことが多く、方向が逆になることもあります。
- 本サイトはEIAの統計を扱っています。
