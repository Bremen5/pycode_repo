# 監修者のための石油市場テキスト

このフォルダは、サイトの監修者が石油市場について専門家と議論できる水準の知識を身につけるための **非公開の学習テキスト** です。サイトのビルド対象外（`content/` ではない）なので、公開されることはありません。

- 作成：2026年10月
- 前提：高校卒業程度の数学（比・割合・加減乗除）。経済や金融の予備知識は不要
- 分量：全13章。1章あたり30〜60分。通読するとおよそ2〜3週間（1日1章ペース）

> **最新の数値について**：本テキストの数値（生産量・税率・制度など）は作成時点の知識にもとづく目安です。年によって変わるものには「（要確認）」と付けています。サイトの記事で使う前に、必ず一次情報（EIA、IEA、OPEC、資源エネルギー庁など）で最新の値を確認してください。

## おすすめの進め方

1. **第1週**：1〜4章で「モノの流れ」（原油→精製→製品→消費）を理解する
2. **第2週**：5〜8章で「数字と価格」（統計・価格指標・先物・情報源）を理解する
3. **第3週**：9〜11章で「出来事と実務」を押さえ、12章の練習問題で確認する
4. **以後**：毎週の監修のたびに11章のチェックリストを使い、わからない用語は13章で引く

## 毎週の監修と組み合わせる

テキストを読み終える前から、毎週の監修でこう使うと効率よく身につきます。

- 下書きに出てきた用語を13章で引き、その用語が出てくる章を読む
- 「今週のポイント」に出た項目（例：留出油在庫が5年最低）について、その背景にある仕組みを該当する章で確認する
- EIAの週報本文（WPSRのHighlights）を毎週1回、英語のまま読む（5章・13章を参照）
