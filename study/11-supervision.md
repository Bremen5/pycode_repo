# 第11章 監修の実務

**この章の到達目標**
- 毎週の解説を、15〜30分で正確にチェックできる
- よくある誤りのパターンを見抜き、修正案を示せる
- 投資助言・広告表示などの法令上の注意点を理解し、表現を判断できる

---

## 11.1 監修者の役割

監修者の仕事は、文章を書き直すことではなく、次の4点を保証することです。

1. **正確性**：数字・事実・用語が正しい
2. **妥当性**：数字が支持する範囲を超えた解釈をしていない
3. **中立性**：一方的な見方や、売買を促す表現がない
4. **出典**：根拠が示され、利用条件を守っている

## 11.2 毎週の監修チェックリスト

`CLAUDE.md` の手順と組み合わせて使います。所要時間の目安つきです。

### A. 数字（10分）

- [ ] タイトルの前週比の数字と、増減の向き（増／減）が `data/weekly` と一致している
- [ ] 3行の要約の数字が本文・表と一致している
- [ ] 単位：在庫は「万バレル」、生産・輸出入・需要は「日量〇万バレル」、稼働率は「%」と「ポイント」
- [ ] 「過去5年の平均を〇%上回る／下回る」の向きが正しい
- [ ] 「〇週連続」「〇週ぶり」が正しい（グラフの直近数週で目視確認）
- [ ] キロリットル換算の桁（1万kL＝約6.29万バレル）
- [ ] 価格：週平均とその週の終値を混同していない。ドル/バレルとドル/ガロンを混同していない
- [ ] CFTC：火曜日時点の数字であること、枚数（1枚＝1,000バレル）

### B. 用語と定義（5分）

- [ ] 原油在庫は「戦略石油備蓄（SPR）を除く」
- [ ] 留出油に「ジェット燃料」を含めていない
- [ ] 「需要」はガソリンの製品供給量（見かけの需要）
- [ ] 発表日（日本時間）と集計週（〇月〇日までの週）を取り違えていない

### C. 解釈と表現（10分）

- [ ] 在庫の増減と価格の動きを、因果関係として断定していない
- [ ] 売買の推奨、タイミング、価格の予想がない
- [ ] 評価語（「強気」「弱気」「好材料」「悪材料」「買い場」）を使っていない
- [ ] 背景の説明に出典がある。推測を事実のように書いていない
- [ ] 予測値（STEOなど）は「EIAの見通し」と明示している

### D. 公開前（5分）

- [ ] 【要確認】がすべて消えている
- [ ] `draft: false` と `date:` を設定した
- [ ] `npm run build` と `npm test` が通った
- [ ] プレビューで表とグラフの表示を確認した

## 11.3 よくある誤りと修正例

| # | 誤りの例 | 問題 | 修正例 |
|---|---|---|---|
| 1 | 原油在庫が日量300万バレル減少 | ストックにフローの単位 | 原油在庫が300万バレル減少 |
| 2 | 原油生産量が10万バレル増加 | フローに「日量」がない | 原油生産量が日量10万バレル増加 |
| 3 | 稼働率が1.5%上昇 | %とポイントの混同 | 稼働率が1.5ポイント上昇 |
| 4 | 在庫が減少したため価格が上昇 | 因果の断定 | 在庫は〇万バレル減少した。同じ週のWTIの週平均は〇ドル上昇した |
| 5 | 原油在庫（SPRを含む）が… | 定義の混在 | 原油在庫（SPR除く）とSPRを分けて記載 |
| 6 | 需要が急減し、景気の悪化を示した | 一週の振れの過大解釈 | ガソリンの製品供給量は前週比〇%減少した（週ごとの振れが大きい項目のため、4週平均では〇） |
| 7 | 投機筋が強気に転じた | 評価語 | マネージドマネーの買い越しは〇枚で、前週から〇枚増加した |
| 8 | OPECが減産を決めたので供給は減る | 目標と実績の混同 | OPECプラスは〇月からの生産目標を〇万バレル引き下げることで合意した |
| 9 | 原油価格は今後上昇が見込まれる | 予想 | EIAの短期見通し（〇月）は、〇〇と見込んでいる（出典を明示） |
| 10 | 米国の在庫減で日本のガソリンも値上がりへ | 因果と予測 | 削除するか、日本の価格は為替・税・補助金の影響が大きいことを説明 |
| 11 | 過去最低の在庫 | 比較範囲が不明 | 過去5年の同じ週で最も少ない水準（または「〇年〇月以来の低水準」と根拠を示す） |
| 12 | 発表日の週と集計週の取り違え | 日付の誤り | 「10月9日までの週」（発表は10月15日） |

## 11.4 表現のガイド

### 使ってよい表現（事実の記述）

- 〜した、〜となった、〜を上回った／下回った
- 前週比で〇万バレル増加した
- 過去5年の同じ週の平均を〇%下回る水準
- 〇週連続の減少

### 避ける表現

| 区分 | 例 |
|---|---|
| 売買の推奨 | 買い時、売り時、仕込み、〜すべき |
| 価格の予想・断定 | 上昇するだろう、下落は避けられない、底を打った |
| 評価語 | 強気、弱気、好材料、悪材料、ポジティブ、ネガティブ |
| 因果の断定 | 〜したため価格が上昇した、〜が嫌気された |
| 誇張 | 爆上げ、暴落（大きな下落の事実を書くときは数字で示す） |

### 迷ったときの判断基準

「この文は、読者に特定の売買の判断を促すか？」と自問します。促すおそれがあれば書き換えます。

## 11.5 法令上の注意点（概要）

以下は監修者が知っておくべき概要で、法的助言ではありません。運用方針に迷うときは専門家に相談してください。

### 金融商品取引法（投資助言）

報酬を得て、有価証券やデリバティブの価値、投資の判断について助言する契約を結ぶ事業は「投資助言・代理業」にあたり、登録が必要です。原油先物などの商品デリバティブにも、関連する規制（商品先物取引法など）があります。

本サイトのように、**不特定多数に向けて無料で一般的な情報を提供する** 形は、通常この登録の対象とは考えられていません。ただし、

- 有料会員向けに個別の売買を勧めるサービスを始める
- 特定の金融商品の売買に誘導する広告・リンクを記事と一体化させる

といった場合は、規制の対象になりうるため、事前に専門家に確認が必要です。

### 景品表示法（ステルスマーケティング規制）

2023年10月から、広告であることを隠した宣伝（いわゆるステマ）が景品表示法の不当表示として規制されています。本サイトの広告枠に必ず「PR」と表示しているのはこのためです。記事の中で特定の事業者の商品・サービスを紹介し、報酬を受け取る場合（アフィリエイトなど）も、広告であることを明示する必要があります。

### 電気通信事業法（外部送信規律）

2023年6月から、一定の事業者には、利用者の端末からの情報の外部送信（アクセス解析のタグなど）について、内容を公表するなどの義務が課されています。対象となる事業の範囲には、ニュースなどの各種情報をオンラインで提供するサービスも含まれうるとされます。本サイトはGoogle アナリティクスを使うため、プライバシーポリシーに「外部送信について」の項目を設けています（送信先・送信される情報・目的）。

### 著作権・データの利用条件

- EIA・CFTCなど米国政府のデータは、原則として自由に利用できる（ただしEIAのページでも、第三者が提供するデータ（スポット価格など）には条件がある場合がある）
- 価格報告機関・取引所の価格データは、原則として有料・ライセンス制
- 報道の引用は、出典を明示し、引用の必然性と主従関係を守る（記事の大部分を転載しない）
- グラフ・画像の転載には許諾が必要

## 11.6 訂正の運用

1. 誤りの連絡・発見があったら、まず元データで事実を確認する
2. 誤りであれば、速やかに修正し、記事の `updated:` に日付を入れる
3. 数字の誤りなど重要な訂正は、本文の末尾に「〇月〇日：〇〇の数値を訂正しました」と記載する
4. 同じ誤りが繰り返されないよう、チェックリストやテンプレート（`scripts/draft.mjs`）を見直す

## 11.7 監修者として成長するために

- **毎週、WPSRのHighlights（英語）を読む**：EIA自身が何を重要と見ているかがわかる
- **月に一度、STEO・IEA・OPECの月報の要約を読み比べる**：見方の違いを知る
- **大きな出来事の週は、価格・在庫・建玉を並べて振り返る**：因果を断定せずに事実を整理する練習になる
- **用語集（第13章）を自分の言葉で書き直す**：説明できない用語は理解が足りていない

## この章のまとめ

- 監修の目的は正確性・妥当性・中立性・出典の保証
- チェックリストで「数字→用語→解釈→公開前」の順に確認する
- 因果の断定、予想、評価語を避け、事実を数字で書く
- 投資助言・ステマ規制・外部送信規律・データの利用条件に注意する
