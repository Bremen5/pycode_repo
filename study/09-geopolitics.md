# 第9章 地政学・政策・イベント

**この章の到達目標**
- 石油の供給を左右する主な地政学的リスクを説明できる
- 制裁・備蓄放出・規制などの政策の影響を説明できる
- 過去の大きな価格変動の背景を、需給の言葉で説明できる

---

## 9.1 海上輸送の要衝（チョークポイント）

世界の石油の多くはタンカーで運ばれ、いくつかの狭い海峡を通ります。

| 要衝 | 位置 | 重要性 |
|---|---|---|
| ホルムズ海峡 | ペルシャ湾の出口 | 日量約2,000万バレル（世界の消費量の約2割）が通過するとされる（要確認：最新の推計）。サウジ・イラク・クウェート・UAE・カタール・イランの輸出の出口。日本の輸入原油の大部分も通る |
| マラッカ海峡 | マレーシア・インドネシア間 | 中東からアジアへの最短ルート |
| バブ・エル・マンデブ海峡 | 紅海の南の出口 | スエズ運河とつながる。2023年末以降、船舶への攻撃でタンカーが喜望峰回りに迂回した |
| スエズ運河・SUMEDパイプライン | エジプト | 中東と欧州を結ぶ |
| トルコ海峡（ボスポラス） | トルコ | 黒海（ロシア・カザフスタンの原油）の出口 |

要衝の封鎖や通航の危険が高まると、

- 迂回による輸送日数の増加 → タンカー運賃の上昇、輸送中の在庫の増加
- 保険料の上昇
- 供給途絶への懸念による価格の上昇

といった影響が出ます。

## 9.2 制裁

| 対象 | 概要（要確認：最新の状況） |
|---|---|
| ロシア | 2022年のウクライナ侵攻以降、EUは海上輸送の原油（2022年12月）・石油製品（2023年2月）の輸入を原則禁止。G7などは、ロシア産原油の取引に価格上限を設け、上限を超える取引への海上保険などの提供を禁じた。上限の水準は後に見直されている。いわゆる「影の船団」による輸送も問題になっている |
| イラン | 米国の制裁（第三国の企業にも適用される二次制裁を含む） |
| ベネズエラ | 米国の制裁。緩和と強化が繰り返されてきた |

制裁の影響は、輸出量の減少よりも、**貿易の流れの変化**（輸出先の変更、輸送距離の延長、割引価格での取引）として表れることが多いのが特徴です。

## 9.3 戦略備蓄の放出

- **IEAの協調放出**：IEAの加盟国は、純輸入量の90日分以上の石油備蓄を持つ義務があり、大規模な供給途絶の際には協調して放出する。2022年には2回の協調放出が行われた
- **米国のSPRの放出・買い戻し**：政府の判断による（第5章）

備蓄の放出は、短期的に市場への供給を増やしますが、放出した分は後で買い戻す必要があります。

## 9.4 天候・災害

- **ハリケーン**（大西洋の6〜11月）：メキシコ湾の海上油田の生産停止、湾岸の製油所・港湾の停止。原油の生産・輸入・製油所の稼働のすべてに影響
- **寒波**：2021年2月の米国テキサス州の寒波では、原油の生産と製油所の稼働が大きく落ち込んだ
- **洪水・山火事**：カナダのオイルサンド地域の山火事など

> **監修のポイント**：ハリケーンの週は、在庫統計の数字が大きく振れます。原油の輸入・輸出が港湾の停止で止まり、製油所も止まるため、在庫の増減の解釈には特に注意が必要です。

## 9.5 規制と構造変化

- **気候変動対策**：炭素税、燃費規制、EV支援策。長期の需要に影響
- **船舶燃料の硫黄規制（IMO 2020）**：製品と原油の品質による価格差に影響（第3章）
- **バイオ燃料の混合義務**：米国の再生可能燃料基準（RFS）など。製油所の費用（RINの価格）に影響
- **中国の輸入・輸出の枠**：製油所の原油輸入や製品輸出に影響

## 9.6 歴史に学ぶ大きな価格変動

価格の大きな変動は、ほとんどが「供給の急変」か「需要の急変」で説明できます。

| 時期 | 出来事 | 需給の言葉での説明 |
|---|---|---|
| 1973〜74年 | 第一次石油危機（アラブ産油国の禁輸） | 供給の急減と、産油国による価格決定権の確立 |
| 1979〜80年 | 第二次石油危機（イラン革命、イラン・イラク戦争） | 供給の急減と買いだめ |
| 1986年 | 価格の暴落 | サウジアラビアの増産（市場シェアの回復を優先） |
| 1990年 | イラクのクウェート侵攻 | 供給途絶。短期間で価格が急騰 |
| 1998年 | アジア通貨危機後の低迷 | 需要の減少とOPECの増産が重なる |
| 2008年 | 史上最高値（WTIで1バレル140ドル台）とその後の暴落 | 新興国の需要の急増と余剰能力の減少、その後の金融危機による需要の急減 |
| 2014〜16年 | 価格の急落 | 米シェールの急増と、OPECが減産せずシェアを守った |
| 2016年末 | OPECプラスの発足 | 産油国の協調減産 |
| 2020年 | パンデミック、WTIのマイナス価格 | 需要の急減と貯蔵能力の逼迫（第7章） |
| 2022年 | ロシアのウクライナ侵攻 | 供給途絶への懸念と貿易の流れの変化。欧州の軽油価格が特に高騰 |

> **監修のポイント**：歴史的な比較（「〇〇危機以来の高値」など）は、名目か実質（物価調整後）かで意味が大きく変わります。記事で使う場合は、どちらかを明示しましょう。

## 9.7 イベントの日程を押さえる

- OPECプラスの閣僚会合（定例は年2回程度。月次の会合もある）
- 米国の祝日（統計の発表がずれる）
- 大西洋のハリケーン・シーズン（6〜11月）
- 製油所の定期修理シーズン（春・秋）
- 米国のドライブシーズン（5月下旬〜9月上旬）
- 主要国の選挙、制裁の期限

## この章のまとめ

- ホルムズ海峡は世界の石油の約2割が通る最重要の要衝。日本にとっても生命線
