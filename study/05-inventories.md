# 第5章 在庫とEIA週間統計を深く読む

**この章の到達目標**
- 在庫の種類と、在庫が持つ経済的な意味を説明できる
- EIAの週間石油在庫統計（WPSR）の構成と数字の成り立ちを説明できる
- 統計の限界（推計・調整項目・修正）を踏まえ、誤読を指摘できる

---

## 5.1 在庫の種類

| 種類 | 内容 |
|---|---|
| 商業在庫 | 民間企業が持つ在庫。製油所、ターミナル、パイプライン、タンクファーム |
| 戦略備蓄（政府備蓄） | 緊急時のために政府が持つ在庫。米国のSPR、日本の国家備蓄など |
| 輸送中の在庫 | タンカーで海上を輸送中の原油（oil on water） |
| 浮体貯蔵 | 輸送ではなく、貯蔵のためにタンカーにとどめている原油。価格の期間構造が大きなコンタンゴのときに増える |

### 「使える在庫」と「使えない在庫」

タンクやパイプラインには、操業のために常に一定量の原油が必要です（タンクの底やパイプラインを満たす分）。そのため、統計上の在庫がゼロになることはなく、**最低操業水準** を下回るとそれ以上の取り崩しは難しくなります。逆に、タンクの容量の上限（タンクトップ）に近づくと、受け入れが難しくなります。

### 在庫の「日数」

在庫の多さを需要と比べた「何日分か」で表すことがあります（在庫 ÷ 1日あたりの需要）。需要の規模が変わる長期の比較では、絶対量より日数の方が適切な場合があります。

## 5.2 在庫が持つ意味

在庫は、生産と消費のずれを吸収するクッションです。

- **在庫の増加**：その期間、供給が需要を上回った
- **在庫の減少**：その期間、需要が供給を上回った

在庫の水準は、先物の期間構造とも深く関係します（第7章）。在庫が少なく需給が引き締まっているときは、すぐに手に入る原油の価値が高くなり、期近の価格が期先より高い（バックワーデーション）状態になりやすいとされます。

## 5.3 米国の戦略石油備蓄（SPR）

- 1970年代の石油危機を受けて創設（1975年のエネルギー政策・保全法にもとづく）
- テキサス州とルイジアナ州の4か所の地下の岩塩層の空洞に貯蔵
- 貯蔵能力は約7億バレル強
- 2022年、ロシアのウクライナ侵攻後の価格高騰を受けて大規模な放出が行われ、在庫は1980年代以来の低い水準になった。その後、買い戻しが進められている（要確認：最新の在庫量と政策）

SPRの増減は、政府の判断によるもので、民間の需給とは別の理由で動きます。**商業在庫とSPRを合算した数字と、商業在庫だけの数字を混同しない** ことが重要です。

## 5.4 WPSRの構成

EIAの週間石油在庫統計（Weekly Petroleum Status Report）は、多くの表から成り立っています。主なものは次のとおりです。

| 内容 | 主な数字 |
|---|---|
| 米国の石油の需給の概要 | 原油の生産、輸入、輸出、製油所への投入、製品の生産、製品供給量 |
| 在庫 | 原油（SPR除く・SPR）、ガソリン、留出油、ジェット燃料、プロパン、その他 |
| 地域別（PADD別） | 5つの地区ごとの在庫・製油所の稼働など。クッシングの在庫もここ |
| 製油所 | 投入量、稼働率、製品の生産量 |
| 輸出入 | 原油・製品の輸入量と輸出量、国別の輸入 |

本サイトが毎週扱う10項目は、このうちの主要な数字です。

### 数字はどう集められているか

製油所、ターミナル、パイプライン、輸入業者などを対象に、EIAが報告義務のある週次調査を行っています。調査は大口の事業者が中心で、小規模な事業者の分は推計で補われます。輸出入には税関（通関）の情報も活用されています。原油の生産量は、利用可能なデータにもとづく推計値です。

## 5.5 調整項目（Unaccounted-for Crude Oil）

原油の需給表では、

> 生産 ＋ 輸入 − 輸出 − 製油所への投入 − 在庫の増加 ＝ 0

となるはずですが、実際には測定の誤差やタイミングのずれで一致しません。この差を埋めるのが **調整項目（unaccounted-for crude oil）** です。

調整項目が大きい週は、どこかの数字（輸出入、生産の推計など）に誤差がある可能性を示します。専門家は、調整項目の大きさを見て、その週の在庫の変化をどこまで信頼するかを判断することがあります。

## 5.6 在庫の増減を分解して考える

ある週の原油在庫の変化は、次の要素に分解できます（単位をバレル/日にそろえて7倍すると週の変化量）。

> 在庫の変化 ≒（生産 ＋ 輸入 − 輸出 − 製油所の投入 ＋ 調整項目）× 7

**例**：原油在庫が500万バレル減った週を分析すると……

| 要素 | 前週比の変化（日量） | 在庫への影響（週） |
|---|---|---|
| 輸入 | −50万バレル | −350万バレル |
| 輸出 | +20万バレル | −140万バレル |
| 製油所の投入 | +10万バレル | −70万バレル |
| 生産 | 0 | 0 |
| 調整項目 | +10万バレル | +70万バレル |

この例では、在庫の減少の大部分が **輸入の減少と輸出の増加**、つまり貿易のタイミングで説明できます。このような週は、需要の強さを示す取り崩しとは性格が異なります。

> **監修のポイント**：「原油在庫が大幅に減少＝需要が強い」と書かれていたら、輸出入と製油所の投入の数字を確認しましょう。貿易の振れによる減少であれば、次の週に反動が出ることも珍しくありません。

## 5.7 週次統計を読むときの専門的な注意点

1. **4週平均で見る**：製品供給量・輸出入は週ごとの振れが大きい
2. **過去5年との比較の落とし穴**：過去5年に2020年（パンデミック）のような特殊な年が含まれると、平均や範囲がゆがむ
3. **ガソリン在庫の構成**：完成品のガソリンと混合用基材（ブレンディング・コンポーネント）を含む。基材の増減で動くこともある
4. **留出油の内訳**：硫黄分による区分がある。暖房油の需要がある北東部（PADD 1）の在庫が注目される
5. **ジェット燃料は別項目**：留出油には含まれない
6. **合計在庫**：原油と製品を合わせた「商業在庫の合計」の動きを見ると、精製による原油から製品への移し替えの影響を除いた全体像がわかる
7. **修正**：週次の数字は、月次統計（PSM）で修正されることがある。特に輸出入・製品供給量・生産
8. **祝日**：発表日がずれても、集計期間（金曜日終わりの1週間）は変わらない

## 5.8 API統計との関係

前日（火曜の夕方、米東部時間）に伝えられるAPI（米国石油協会）の統計と、EIAの統計は、同じ週について数字が異なることがよくあります。報告が任意か義務か、対象範囲、推計方法の違いによるものです。サイトのガイド「API統計との違い」も参照してください。

## 5.9 世界の在庫

- **OECDの商業在庫**：IEAやEIAが推計。約27〜28億バレル程度（要確認）。過去5年の平均との差が需給の引き締まりの目安としてよく使われる
- **中国の在庫**：公式統計が限られ、衛星画像などからの推計に頼る部分が大きい
- **海上の在庫**：タンカーの追跡データで推計

## この章のまとめ

- 在庫は供給と需要のずれのクッション。期間構造とも関係する
- 商業在庫とSPRを混同しない
- 在庫の変化は「生産・輸入・輸出・製油所の投入・調整項目」に分解して考える
- 調整項目が大きい週は、数字の信頼性に注意
- 週次は4週平均、5年比較の特殊年、月次での修正に注意
